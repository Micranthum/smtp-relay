# Scripts de utilidad para SMTP Relay

Este directorio contiene scripts útiles para pruebas y mantenimiento.

## test_email.py

Script para probar el envío de emails a través del relay.

### Uso:

```bash
python scripts/test_email.py
```

Edita el script para configurar:
- Servidor SMTP relay
- Credenciales
- Remitente y destinatario
